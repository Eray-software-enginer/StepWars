# StepWars2 - Gamified Pedometer & RPG Card Game

StepWars2, hareketsiz yaşam tarzına karşı kullanıcıları yürümeye teşvik etmek amacıyla geliştirilmiş yenilikçi bir mobil Android projesidir. 

### Öne Çıkan Özellikler

* 🚶‍♂️ **Adım Sayar (Pedometer):** Arka planda çalışan donanım sensörü ile gerçek hayatta attığınız adımlar, oyun içi para birimine ("Adım Altını") dönüşür.
* 🃏 **RPG Kart Sistemi:** Toplanan altınlarla mağazadan sandıklar açılır ve farklı özelliklere sahip karakter kartları toplanarak savaş destesi oluşturulur.
* ⚔️ **Gerçek Zamanlı Savaş (PVP Arena):** Çevrimiçi eşleştirme (Matchmaking) sistemi ile oyuncular gerçek zamanlı, sıra tabanlı (turn-based) kart savaşları yapar.
* 🛡️ **Klan Sistemi:** Oyuncular kendi klanlarını kurabilir, klan içi rolleri yönetebilir ve diğer üyelerle gerçek zamanlı sohbet (chat) edebilirler.

### Teknoloji Yığını (Tech Stack)

* **Dil:** Kotlin
* **Arayüz (UI):** Jetpack Compose, Material Design 3
* **Mimari:** MVVM (Model-View-ViewModel)
* **Backend & Veritabanı:** Firebase (Auth, Cloud Firestore, Realtime Database)
* **Yerel Veri Saklama:** Jetpack DataStore
